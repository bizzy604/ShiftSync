# **How to Use These Prompts with Google Stitch**

Google Stitch works best with focused, sequential prompts. Follow this workflow for every screen:

**Step 1 — Open Google Stitch:** Go to stitch.withgoogle.com and sign in. Choose Experimental Mode (Gemini 2.5 Pro) for the best output quality on complex screens.

**Step 2 — Start a new project:** Click 'New Project'. Give it a name like 'ShiftSync — Manager Screens'.

**Step 3 — Paste the Initial Prompt:** Copy the INITIAL STITCH PROMPT from this document and paste it into Stitch's input box. Click Generate. Wait for the full output before doing anything else.

**Step 4 — Review carefully:** Check every component listed in the prompt is present. Take a screenshot before proceeding.

**Step 5 — Apply Follow-Up Prompts one at a time:** Paste each FOLLOW-UP PROMPT individually, in order. Wait for the generation to complete before pasting the next one. Applying multiple follow-ups at once causes Stitch to break the layout.

**Step 6 — Export:** When you are satisfied, click 'Paste to Figma' or 'View Code' to export. HTML/CSS output uses Tailwind CSS.

# **Global Stitch Tips for ShiftSync**

Apply these tips across all screen generations to maintain consistency:

* Consistency pass: After generating all screens for a role, use Stitch's multi-select feature (Shift+click) to apply a single prompt: 'Ensure consistent font sizes, button styles, and color usage across all selected screens.'

* Navigation bar: Generate the nav bar once as its own Stitch screen. Then in every other screen prompt, reference it: 'Use the same navigation bar from the ShiftSync Login screen — dark navy background, white logo, notification bell, avatar.'

* Role colour coding: Always include the role accent colour explicitly in each prompt. Manager \= teal \#0A7C6E, Staff \= purple \#5C3D8F, Admin \= slate \#3A4F66.

* Constraint error states: All constraint violation messages follow this format — include it in any prompt showing errors: 'Rule name, severity badge, specific numbers (actual gap vs minimum), and a list of suggested alternative staff below.'

* Timezone display: All shift times shown in the UI use the shift location's IANA timezone, never UTC. Include in prompts: 'Show times in the location timezone (America/Los\_Angeles), not UTC.'

* Empty states: Every list screen (swap queue, notifications, staff list) needs an empty state. Generate the default state first, then add the empty state in a follow-up: 'Show the empty state when there are no items — a centered illustration and supportive message text.'

* Stitch generation limit: You get 50 Experimental Mode generations per month. Use Standard Mode (Gemini Flash) for quick layout exploration and switch to Experimental for final polish.
